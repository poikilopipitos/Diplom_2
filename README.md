# Diploma — Часть 2. API-тесты для Stellar Burgers

## О проекте

Вторая часть дипломного проекта посвящена автоматизированному тестированию REST API сервиса Stellar Burgers.

Проект реализован на Python с использованием Pytest и библиотеки Requests. Для анализа результатов выполнения тестов используется Allure Report.

В рамках проекта автоматизированы основные пользовательские сценарии работы API: регистрация пользователей, авторизация и создание заказов.

## Проверяемая функциональность

### Создание пользователя

Проверено:

- успешное создание нового пользователя;
- невозможность регистрации уже существующего пользователя;
- создание пользователя без одного из обязательных полей.

### Авторизация пользователя

Проверено:

- успешный вход существующего пользователя;
- вход с неверным логином или паролем.

### Создание заказа

Проверено создание заказа:

- авторизованным пользователем;
- без авторизации;
- с корректными ингредиентами;
- без ингредиентов;
- с некорректным хешем ингредиентов.

## Установка проекта

Клонировать репозиторий:

git clone <ссылка_на_репозиторий>
Перейти в папку проекта:

cd Diploma_API
Создать виртуальное окружение:

python -m venv venv
Активировать окружение.

Windows

venv\Scripts\activate
Linux/macOS

source venv/bin/activate
Установить зависимости:

pip install -r requirements.txt
## Запуск тестов

Запуск всех тестов:

pytest
Подробный вывод:

pytest -v
## Формирование Allure-отчёта

Выполнить тесты:

pytest --alluredir=allure_results
Открыть отчёт:

allure serve allure_results
или сформировать статический отчёт:

allure generate allure_results -o allure_report
## Особенности проекта

- Тесты полностью независимы друг от друга.
- Для регистрации используется генерация уникальных пользователей.
- Проверяются как позитивные, так и негативные сценарии работы API.
- В тестах выполняется проверка не только кодов ответа, но и содержимого тела ответа.
- Отчёты Allure позволяют быстро анализировать результаты выполнения тестов.
